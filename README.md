# KronOS

A persistent desktop workspace for terminals, browsers, files, and AI agents.

This repository contains public downloads, release notes, and support issues. The
application source is maintained separately in a private repository.

## Downloads

Open [Releases](https://github.com/Ahmedalsadi-1/kronos-releases/releases) for
published installers. Each release lists its supported architecture, signing
status, installation instructions, and known issues. If no release is listed,
there is no published installer yet.

macOS is the initial distribution target. Windows and Linux remain under
evaluation. The iPhone client is Labs work.

## Bring your own model

Connect a model provider using your own API key, use a supported provider sign-in,
or configure a compatible local model. No KronOS account is required. Provider
usage and any provider subscription are billed by your provider. Optional tools
can require their own accounts or installed runtimes.

## Report a problem

In KronOS, open **Settings > About > Diagnostics & support**. Preview and copy the
support report, then [open an issue](https://github.com/Ahmedalsadi-1/kronos-releases/issues/new?template=bug-report.yml).
Include what you were doing, what you expected, and steps to reproduce the issue.

Reports contain the app version, platform, failure category, and shipped code
locations. Diagnostics stay on your device until you choose to share them. No
reporting service, tracking key, or automatic upload is used. The local history
keeps up to 50 recent failures and can be cleared in Settings.

GitHub issues are public and require a GitHub account. Review text and
attachments before submitting. Never include API keys, credentials, private
conversations, client files, or terminal output that contains sensitive data.
